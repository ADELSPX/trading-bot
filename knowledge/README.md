### 1️⃣ أنماط القاما (Gamma Patterns) — جوهر الاستراتيجية
📄 `patterns/gamma/gamma-patterns-full.md` — **23 مبدأ + 22 نمط مرئي كامل**

**أهم المبادئ (ملخص سريع):**
| # | المبدأ | القاعدة |
|---|--------|---------|
| 1 | المركز ≠ البرج | المركز = سيولة الصانع الحقيقية (رقم استرايك) — البرج = أثر الشارت |
| 3 | شرط الدخول | شمعة 5 دقائق: خضراء فوق المركز (كول) / حمراء تحت المركز (بوت) — **غير ملامسة** |
| 4 | مراكز الصانع | أرقام استرايكات — الفريم ما يغير المبدأ |
| 5 | لا مؤشر | لا مؤشر يعطيك سيولة الصانع — المؤشرات = بيانات سابقة |
| 8 | القاعدة الذهبية | الصفقة الصحيحة = شرط الدخول يتحقق من **سيولة الصانع نفسه** |
| 10 | سيولتين | سيولتين مع بعض اتجاه واحد = دخولك |
| 15 | فوق الإجماع | سيولة الصانع تتغلب على إجماع العالم كله |
| 20 | البساطة | الاستراتيجية = كول + بوت + وقف عند مركز السيولة فقط |
| 21 | GEX ≠ قاما | أعمدة GEX = كلام فاضي — القاما شارت بصري |
| 22 | المعادلة | السوق = سيولة الصانع (مراكز لحظية) + سيولة المناطق (عرض/طلب) |

**نظام العلامات (قراءة شارت فهد):**
- ✅️ = هدف أول / ✅️✅️ = هدف ثاني
- ⛔️ = قاع أول / ⛔️⛔️ = قاع ثاني
- 👑 = الفيصل بين الكول والبوت
- 💰💰💰 = مراكز سيولة الصانع
