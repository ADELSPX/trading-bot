# 📊 أنواع الاختراق — Breakout Types

## الوصف
الاختراق هو كسر السعر لمستوى دعم/مقاومة مهم بكمية وحجم. تحديد **نوع الاختراق** يحدد اتجاه الصفقة:
- **اختراق صاعد** = كسر مقاومة → شراء Call
- **اختراق هابط** = كسر دعم → شراء Put

## الأنماط الرئيسية

### 1. القمة المزدوجة (M — Double Top) → هبوط
```
       /\
      /  \      ← قمتان متساويتان
     /    \
    /      \
   /        \__
  /            \  ← كسر خط الرقبة = إشارة بيع
 /
```
- **شروط الدخول:** كسر **خط الرقبة** (Neckline) بعد القمة الثانية
- **الهدف:** مسافة القمم → خط الرقبة (بنفس الارتفاع)
- **الوقف:** فوق القمة الثانية بقليل
- **الاتجاه:** PUT

### 2. القاع المزدوج (W — Double Bottom) → صعود
```
      /\
     /  \      ← قاعان متساويان
    /    \
   /      \__
  /          \
 \            \__  ← كسر خط الرقبة = إشارة شراء
  \              \
```
- **شروط الدخول:** كسر **خط الرقبة** بعد القاع الثاني
- **الهدف:** مسافة القيعان → خط الرقبة (بنفس الارتفاع)
- **الوقف:** تحت القاع الثاني بقليل
- **الاتجاه:** CALL

## شروط الدخول القابلة للتنفيذ (Entry Conditions)
1. تشكل النمط على **إطار زمني كبير** (4H/يومي) — إشارات أقوى
2. **حجم التداول** يؤكد الاختراق (حجم أعلى من المتوسط)
3. **كسر واضح** لخط الرقبة — إغلاق شمعة بعد الكسر (مو شمعة واحدة)
4. **عدم وجود سيولة صانع (MM) معاكسة** عند المستوى (تحقق القاما)
5. **GEX موجب** للدعم الصاعد / **GEX سالب** للهبوط

## إدارة المخاطر (Risk Management)
- **الوقف:** خارج النمط (فوق/تحت القمة/القاع)
- **نسبة المخاطرة:** 1:2 على الأقل (هدف = ضعف الوقف)
- **حجم الصفقة:** لا يتجاوز 1-2% من رأس المال
- **لا دخول** إذا كان الاختراق بدون حجم أو وسط تراجع

## نقاط القوة (من فهد)
- **شرط دخول القاما:** الدخول من سيولة صانع (MM) فقط
- **لا دخول بدون تحقق السيولة** عند المستوى
- الاختراق الحقيقي = اختراق + تراجع (Pullback) + استمرار
