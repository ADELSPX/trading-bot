# 🤖 Trading Bot — بوت تداول ذكي

> مبنية على تحليل أكثر من 5 فيديوهات تدريبية في تداول الخيارات (Options).
> استراتيجيات مستخلصة، قواعد برمجية، وجاهز للتطوير.

## 📊 الرؤية

تحويل المعرفة من فيديوهات تدريبية إلى **بوت تداول آلي** يفهم السوق وينفذ الصفقات بناءً على:
- **فيبوناتشي** لتوقع حركة السعر
- **معادلة الدلتا** لحساب سعر العقد بعد الحركة
- **إدارة المخاطر** لكل صفقة

## ✅ المنجز (من الفيديوهات)

| # | المحتوى | الحالة |
|---|---------|--------|
| 1 | أساسيات TradingView والشارت | ✅ |
| 2 | استراتيجية Put Options + فيبوناتشي | ✅ |
| 3 | تنفيذ عملي + حاسبة التكلفة | ✅ |
| 4 | 🔥 الدلتا وحسابات الحدود | ✅ |
| 5 | أنواع الأوامر وأوقات التداول | ✅ |
| 6+ | باقي الفيديوهات | ⏸️ ينتظر الرفع |

## 🧠 الاستراتيجية الأساسية

### 🔑 معادلة الدلتا الذهبية
```
سعر العقد بعد الحركة = سعر العقد الحالي - (الدلتا × مقدار حركة السهم)
```

### 📐 اختيار Strike
- بناءً على **توقع السعر** — مو السعر الحالي
- استخدم فيبوناتشي لتحديد الهدف

### ⏰ الأوقات
- ⛔ لا تتداول آخر ساعة (الوقت يقتل العقد)
- ✅ الأفضل: عقود يومية

### 📋 إدارة المخاطر
- تكلفة العقد = عدد العقود × سعر العقد × 100
- حدد الخسارة المستهدفة قبل الدخول
- اغلق عند الهدف — لا تطمع
