# معادلة الدلتا — أمثلة وتوضيحات

## الصيغة الأساسية

```
سعر العقد الجديد = سعر العقد الحالي - (الدلتا × تغير السهم)
```

## أمثلة عملية

### مثال 1: شراء Put (توقع نزول)
| المعامل | القيمة |
|---------|--------|
| سعر العقد الحالي | $0.25 |
| الدلتا | 0.17 |
| توقع النزول | $1 |
| سعر العقد بعد النزول | **$0.08** |

### مثال 2: Call (توقع صعود)
| المعامل | القيمة |
|---------|--------|
| سعر العقد الحالي | $0.50 |
| الدلتا | 0.35 |
| توقع الصعود | $2 |
| سعر العقد بعد الصعود | $0.50 + (0.35 × 2) = **$1.20** |

لاحظ: للـ Call نضيف (السعر يزيد مع صعود السهم)، للـ Put نطرح (السعر يزيد مع نزول السهم).

### مثال 3: دلتا عالية (ITM)
| المعامل | القيمة |
|---------|--------|
| سعر العقد الحالي | $2.00 |
| الدلتا | 0.70 (In the Money) |
| توقع الحركة | $0.50 |
| سعر العقد الجديد | $2.00 - (0.70 × 0.50) = **$1.65** |

### مثال 4: دلتا منخفضة (OTM بعيد)
| المعامل | القيمة |
|---------|--------|
| سعر العقد الحالي | $0.05 |
| الدلتا | 0.05 |
| توقع الحركة | $1.00 |
| سعر العقد الجديد | $0.05 - (0.05 × 1.00) = **$0.00** |

⚠️ العقد يرجع للصفر — يعني توقع الحركة ما يكفي لأن Strike بعيد جدًا.

## ملاحظات مهمة

1. **الدلتا تتغير** مع تغير سعر السهم — هي ليست ثابتة
2. **Gamma** هو معدل تغير الدلتا — ما يخصنا في الفيديوهات الخمسة
3. **Theta (ثيتا)** هو تآكل الوقت — يقتل العقد كلما اقترب expiry
4. الدلتا للـ Call: 0 إلى 1 (إيجابي)
5. الدلتا للـ Put: -1 إلى 0 (سلبي)
6. الدلتا = 0.50 يعني العقد يتحرك بنصف حركة السهم
