# 🎯 Vending-Bench للتداول — خطة محاكاة الالتزام (9/9/2026)

> الفكرة مستوحاة من Vending-Bench 2 (Andon Labs): أعطِ استراتيجية/وكيلاً رأس مالاً
> وهمياً وسنة كاملة، وقِس من يثبت التزاماً طويل المدى بلا "ذوبان" ولا كسر قواعد.
> عندنا نطبقها على إشارات Gamma: هل الاستراتيجية تصمد ربحية وتلتزم بوقف الخسارة؟

## المشكلة الحالية
- إشارات Gamma تُرسل للتليجرام — لكن **لا أحد يتابع مصيرها** (هل حققت الهدف؟ ولا ضربت الوقف؟)
- بلا تتبع = بلا تعلم = لا نعرف هل القواعد فعلاً مربحة
- التغريدات اليومية (وكلاء يربحون $250K) = ادعاءات بلا منهجية — عندنا نقدر نعملها صح

## الأقسام الثلاثة

### المرحلة 1 — دفتر تتبع حي (Paper Ledger) ← نبدأ بها الحين
**المبدأ:** كل إشارة Gamma حقيقية تتحول لصفقة Paper مسجلة، ونراقب مصيرها آلياً.

1. سكربت `tools/vending_ledger.py`:
   - يقرأ `data/gamma_signals.json` (الإشارات الجديدة من القواعد الفعلية)
   - يفتح "صفقة Paper": CALL/PUT + سعر دخول + stop + target1 + target2
   - يخزن في `data/vending_trades.json` (دفتر)
2. متابعة يومية (cron 21:35 — بعد فحص القاما 21:30):
   - يحدّث الصفقات المفتوحة بسعر السوق (yfinance)
   - الإغلاق: ضرب stop = خسارة مسجلة | ضرب target = ربح مسجل | انتهاء أفق زمني (مثلاً 10 أيام) = إغلاق بسعر السوق
   - الالتزام يُقاس: هل الصفقة "التزمت" بالوقف (ما تعدّت stop ثم رجع السوق ضدها)؟
3. تقرير شهري: العائد، win rate، متوسط ربح/خسارة، **نسبة الالتزام** (عدد صفقات احترمت stop/target)
4. التكلفة: صفر LLM — بايثون + yfinance

**مخرجات المرحلة 1:** بعد 30-60 يوم إشارات حية = إحصاء حقيقي: هل قواعد Gamma تلتزم وتربح فعلاً؟

### المرحلة 2 — محاكاة تاريخية (Backtest كامل)
عندما تتوفر بيانات GEX تاريخية أو نعيد بناء مستويات العرض/الطلب من السعر:
- جولات متعددة على SPX (كل جولة = سنة محاكاة) بنوافذ مختلفة (2020-2026)
- تطبيق قواعد الدخول/الخروج نفسها على بيانات قديمة
- مقاييس Vending: رأس المال النهائي + min/max عبر الجولات + نسبة الالتزام
- **معيار القبول:** أسوأ جولة ما تخسر أكثر من X% (مثل Astra: أسوأ جولة > أفضل جولة منافسها)

### المرحلة 3 — (اختياري) وكيل LLM كمدير
مقارنة "قواعد Gamma الصرفة" vs "وكيل LLM يقرر" داخل نفس المحاكاة:
- الوكيل يرى نفس البيانات (مستويات + إشارات + سجل) ويتخذ قرار الدخول/الخروج
- نقيس: هل الوكيل يلتزم بإدارة المخاطر؟ (درس Astra: الرفض عند الخط الأحمر)
- ملاحظة: مكلف (توكنات لكل قرار) — فقط لتقييم الفكرة مو للتشغيل اليومي

## المعايير (مثل Vending-Bench)
| المقياس | التعريف |
|---|---|
| رأس المال النهائي | الرصيد بعد الجولة (يبدأ $100K وهمي) |
| التزام الوقف | % الصفقات اللي احترمت stop (ما كسرته) |
| Max Drawdown | أكبر هبوط من قمة |
| Win rate | % الصفقات الرابحة |
| الاتساق | الفرق بين أفضل/أسوأ جولة |

## قواعد صارمة
1. **Paper فقط — بلا مال حقيقي** حتى تثبت المرحلة 1 (30-60 يوم بيانات)
2. **لا تلمس signal_builder.py** — المحاكاة تقرأ الإشارات، ما تغيرها
3. الإشارات المكررة (نفس الاتجاه خلال X ساعات) = صفقة واحدة (لا مضاعفة)
4. رسوم/انزلاق: $1 لكل صفقة + 0.02% انزلاق (تقدير محافظ)
5. أي تغيير = commit + push فوراً
